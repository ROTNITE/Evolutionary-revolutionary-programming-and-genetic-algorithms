# Лабораторная работа № 2 — дискретная оптимизация с ограничениями

**Статус:** демонстрационный вариант `V=3` (рюкзак с обязательными и взаимоисключающими предметами). Индивидуальный вариант по методичке определяется параметрами `N`, `Q`, `Y`; данных `N`, `Q` пока нет. Формула `d=5+(22 mod 6)=9` была нужна только в ЛР № 1, а в ЛР № 2 размерность определяется числом предметов. Здесь их 40.

## Что входит

- `main.py` — генератор данных и собственный генетический алгоритм без готовой библиотеки оптимизации;
- `test_lab2.py` — 12 модульных тестов;
- `make_report.py` — воспроизводимая сборка отчёта PDF;
- `results/items.csv`, `conflicts.csv`, `instance.json` — исходный синтетический экземпляр;
- `results/runs.csv`, `trajectories.csv`, `summary.json`, `config.json`, `best_solution.csv` — результаты;
- `results/*.png` — блок-схема, динамика, распределение качества и допустимости.

## Запуск (Python 3.10+)

```bash
python -m pip install -r requirements.txt
python main.py --out results --runs 20 --seed-base 2026102000
python -m unittest -v test_lab2.py
python make_report.py
```

Для воспроизводимости данные генерируются через NumPy с `data_seed=2026101802`, запуски используют seed `2026102000–2026102019`. Каждый запуск (четыре конфигурации, по 20 запусков) выполняет **ровно 5522 вычисления исходной целевой функции**. В ГА первые 48 оценок — стартовая популяция, далее по 46 новых потомков за 119 поколений.

## Методы сравнения

1. Генетический алгоритм: восстановление допустимости + побитовая мутация.
2. Генетический алгоритм: штрафные функции + побитовая мутация.
3. Генетический алгоритм: восстановление допустимости + мутация обменом.
4. Случайный допустимый поиск с тем же бюджетом оценок.

Размер популяции 48, турнир `k=3`, равномерный кроссовер `Pc=0.88`, элитизм 2.

## Ограничение результата

Лучшее обнаруженное допустимое решение не обязательно является глобально оптимальным. Жадная эвристика на данном экземпляре достигла той же полезности, что и ГА: это отражено в отчёте без преувеличений.
